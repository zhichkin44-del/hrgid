# ADR-0006. Порог «ответа нет» (ЗАГОТОВКА, не принят)

Статус. Заготовка. Значение не выбрано: подбирается после живой записи, до прогона основной части.

Решение (план). Если оценка верхнего фрагмента после переранжирования ниже порога, поток отвечает «В законе и правилах компании ответа нет» и не вызывает модель ответа. Порог — параметр `FlowConfig.no_answer_threshold` (по умолчанию выключен).

Как подбирается. Только на настроечной части `data/evals/tuning.jsonl` (25 вопросов: 15 закон, 10 «ответа нет»): оценки верхнего фрагмента для обеих групп подаются в `hrgid.flow.threshold.pick_threshold`; берётся порог с наибольшим числом верных исходов, при равенстве — меньший. Основная часть для подбора не используется.

Фиксация. Значение, дата, число верных исходов на настроечной части вписываются сюда отдельным коммитом ДО первого прогона основной части.

Значение: не выбрано. Дата: —. Настроечная часть: — из 25.
